# Project knowledge index

This folder contains planning and source material that supports the site but is not published automatically.

- `brand/` — brand voice and editorial guidance
- `content/blog/` — the editorial roadmap, working drafts, and archived variants
- `operations/` — agent and workflow configuration notes
- `planning/` — sprint and execution plans
- `research/seo/` — keyword, competitor, clickstream, and content-gap research
- `strategy/business/` — positioning, product clarity, and competitive analysis
- `strategy/marketing/` — email, Reddit, and sales-page plans
- `strategy/product/` — product vision and requirements
- `strategy/technical/` — technical architecture notes

## Blog status definitions

- `src/content/posts/`: live/canonical articles used by the Astro content collection
- `docs/content/blog/drafts/`: source drafts or alternate material requiring editorial review
- `docs/content/blog/archive/`: superseded versions retained for reference

Do not infer the number of publishable posts by counting every Markdown file. The canonical published count is the number of non-draft entries in `src/content/posts/`.
