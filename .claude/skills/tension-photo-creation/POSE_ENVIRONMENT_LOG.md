## How to Update This Log

When you create a new blog post image:

1. **Find the corresponding post section** (e.g., blog_bondage-for-beginners.png)
2. **Check the Pose Bank** — Mark the pose you chose as USED
3. **Check the Environment Bank** — Mark the environment you chose as USED
4. **Update the post entry** with:
   - Pose description
   - Environment description
   - Generation date
   - Status (Complete)

**Example update:**

```
### 2. blog_bondage-for-beginners.png
- **Pose:** A figure standing with wrists loosely bound with rope, partner standing closely beside them, suggesting trust and control
- **Environment:** Luxurious, minimalist bedroom with soft window light filtering through sheer curtains at dusk
- **Generated:** 2026-05-20
- **Status:** Complete
```

Then mark those in the banks as USED:
- Pose Bank: Mark "Figures bound loosely with rope" as USED
- Environment Bank: Mark "Minimalist bedroom with clean lines and window light" as USED
